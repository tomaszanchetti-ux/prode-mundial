## Objetivo

Convertir el documento `PRODE MUNDIAL — UX_UI ITERATION V3.md` en backlog ejecutable y ordenado.

El foco no es agregar features nuevas de negocio.
El foco es:

- elevar el sistema visual
- bajar ruido de UI
- reforzar momentos criticos del producto
- resolver identidad de selecciones con banderas confiables
- limpiar copy, estados y navegacion
- dejar la capa social lista para convivir con `Epic 4` sin CTAs fake ni deuda visual fuerte

## Principios binding

- mobile-first real
- no ranking global
- competencia solo dentro de ligas
- backend source of truth
- el flujo de prediccion sigue siendo el centro del producto
- CTA principal azul
- no look SaaS/admin
- no resolver pantallas con mas cards o pills innecesarias
- no mezclar esta epica con implementacion funcional de create/join/detail real de ligas

## Alcance

- uplift de tokens, superficies, spacing y tipografia
- sistema robusto de banderas y `TeamIdentity`
- home hero v3
- prediction flow v3
- compactacion fuerte de fixtures
- polish de standings / leagues sin abrir `Epic 4`
- limpieza de copy, loading, empty states, header y bottom nav

## Fuera de alcance

- create league real
- join por codigo o link real
- league detail real
- ownership rules nuevas
- cambios de reglas de producto
- nuevos modos de juego

## Orden de ejecucion

1. foundation visual
2. flags / identity system
3. navigation + CTA cleanup
4. critical product moments
5. scanability
6. social layer polish
7. final polish + QA

## Resultado esperado

Al cerrar esta epica, la app debe sentirse:

- mas liviana
- mas clara
- mas deportiva
- mas premium
- menos staging
- mejor preparada para abrir `Epic 4`
